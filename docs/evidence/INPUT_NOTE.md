# Input Note

OpenAMP Foundry should make important inputs easy to inspect.

```markdown
## Input note

**Input path:** File, directory, or artifact.

**Purpose:** Why this input is used.

**Version:** Date, commit, release, or local version.

**Known gaps:** Missing fields or incomplete coverage.

**Used by:** Reports, commands, or review packets that depend on this input.

**Next check:** The smallest useful check before reuse.
```

## Acceptance test

An input note is useful when another contributor can see why an input is present, what depends on it, and what limitation travels with it.
